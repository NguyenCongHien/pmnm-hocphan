LibraryMS v0.1
1. Giới thiệu

LibraryMS là ứng dụng web quản lý thư viện được xây dựng bằng Python và Flask.

Các chức năng chính:

Hiển thị tổng số sách.
Hiển thị số sách đang có sẵn.
Hiển thị danh sách sách.
Lọc sách theo thể loại.
Xem chi tiết sách.
API lấy danh sách sách.
API lấy thông tin một sách theo ID.
Xử lý lỗi 404 cho trang HTML và API.
Sử dụng url_for để tạo đường dẫn.
Sử dụng Jinja2 để hiển thị và tự động escape dữ liệu.
